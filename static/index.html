API

OpenAI compatible

Swap your base URL and key. That's it — works with the OpenAI SDK, LangChain, curl, anything that speaks the protocol.

OpenAI Compatible 
# base URL is shown below — your live gateway
import openai

client = openai.OpenAI(
    base_url=…,
    api_key="gw_…",
)
r = client.chat.completions.create(
    model="gpt-oss-120b",
    messages=[{"role": "user", "content": "hi"}],
)
print(r.choices[0].message.content)
# curl example — replace the key and model
curl … \
  -H "Authorization: Bearer $KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-oss-120b","messages":[{"role":"user","content":"hi"}]}'
