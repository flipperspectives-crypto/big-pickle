API — OpenAI compatible

Swap your base URL and key. That's it. Works with the OpenAI SDK, LangChain, llama.cpp, anything that speaks the protocol.

import openai
client = openai.OpenAI(base_url="https://BIGPICKLE_URL/v1", api_key="gw_…")
r = client.chat.completions.create(
    model="local:qwen2.5:0.5b",        # or gpt-4o-mini, gpt-oss-120b, llama-3.3-70b, claude-3-5-sonnet…
    messages=[{"role": "user", "content": "hi"}],
)
print(r.choices[0].message.content)
curl https://BIGPICKLE_URL/v1/chat/completions \
  -H "Authorization: Bearer $KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"local:qwen2.5:0.5b","messages":[{"role":"user","content":"hi"}]}'

Also: GET /v1/models, GET /v1/usage (tokens + balance), POST /v1/signup (create key). Balance is returned on every /v1/usage call.
